# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful and constructive; no harassment, personal attacks,
discrimination, or sustained disruption — in issues, PRs, discussions, and any project
space. Technical disagreement is welcome; make it about the work, with evidence.

Instances of unacceptable behavior may be reported to the maintainer via GitHub
(@Sangaibisi). Reports are handled confidentially. Maintainers may edit, remove, or reject
contributions and comments that violate this code, and may temporarily or permanently ban
contributors for repeated or severe violations.
